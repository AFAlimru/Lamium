状態効果 HUD の見せ方

プレイ中に、いま掛かっている効果の名前・レベル・残り時間を読めるようにする HUD 要素。HUD レイアウトエディタで位置・大きさ・背景を変えられる前提で、見せ方の案を比べる。アイコンは仮の色付き四角（ゲームの画像ではない）。

言語

確認したいこと

  • 見せ方は A / B / C のどれにするか（A を基本にして B を選択肢にする、なども可）。
  • 初期の位置（右上か、左の中ほどか）と、最初からオンにするか。
  • 残りわずかの表し方（色だけ / 点滅 / なし）。点滅は目立つが、うるさく感じるかもしれない。
  • 無期限の効果（コマンドなど）は「∞」で出す。ビーコンの効果は数秒ごとに付け直されるので、残り時間が短いまま点滅し続けないよう、残りわずかの扱いから外すか。
  • 並び順と、多いときにまとめるか。
  • バニラの効果表示（画面のアイコン）は、この HUD がオンのとき隠すか、残すか。
