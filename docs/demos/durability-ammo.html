耐久値 HUD に弾の数を足す

新しい HUD は作らず、耐久値 HUD（左下、アイコン＋バー＋数字の B 表示）を広げる（2026-10-12 メンテナー）。弓を持っているときは矢、クロスボウは矢と花火、エリトラは花火の数。数はインベントリ全体（オフハンドを含む）の合計。アイコンは絵文字の仮置き。ピンクの枠はこの提案で増える部分（実際の画面には出ない）。

場面
弾の数を出す場所
効能付きの矢
防具の行
❤❤❤❤❤❤❤❤❤❤🍗🍗🍗🍗🍗🍗🍗🍗🍗🍗

おすすめ（理由）

  • 武器の行のすぐ下に、小さい行で「🏹 64」を出す。同じ行の右に出す案は行が増えないが、クロスボウ（矢と花火）や内訳を出すと横に長くなり、左下の初期位置ではホットバーにぶつかった（このモックで確認）。下の行なら幅が変わらない。
  • 効能付きの矢は合計に含め、合計だけ出す。弓・クロスボウが撃つ順番（オフハンド → インベントリの先頭）までは表さないので、内訳を出しても「次に何が飛ぶか」は分からない。内訳が欲しければ「合計＋うち効能付き」を設定で選べるようにするのは簡単。種類ごとは行が長くなりすぎる。
  • 弾がゼロのときは赤い「0」。弓を構えても撃てないことがすぐ分かる。
  • 装填済みのクロスボウは、アイコンの角に装填中の弾の小さな印（花火なら 🎆）。文字にすると幅を取る。
  • エリトラ: 防具の行を出していればエリトラ（胸）の行の右に花火の数。防具の行を出していなくても、飛行中だけエリトラの行を出して花火の数を見せる（飛行中に知りたい情報なので）。

確認したいこと

  • 出す場所（おすすめ: すぐ下の小さい行。同じ行の右はホットバーにぶつかることがある）。
  • 効能付きの矢の扱い（合計だけ / 合計＋うち効能付き / 種類ごと。設定で選べるようにするか）。
  • エリトラ: 防具の行がオフでも飛行中だけ行を出すか。
  • 弾の数の表示を設定でオン / オフできるようにするか（おすすめ: 耐久値 HUD の子に「弾の数を表示」、初期値オン）。
