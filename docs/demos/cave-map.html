今いる足場と、空洞の底が分かる地図

普段の探索、上下に重なる足場の確認、保存した洞窟の見返しを続けて試すモックです。洞窟は広く見る／高さを絞るを切り替え、高さは入力・スライダー・記録済み候補から選べます。新しい操作と色は確認中です。地形は架空の説明用データで、ゲームの描画・保存処理の実装結果ではありません。

試してほしい流れ

  • ネザーで「広く見る」→ 橋の上から空洞の底へ：溶岩湖と空洞の輪郭を保ち、重なるところでは現在の足場を優先します。
  • 「高さを絞る」→ Y の欄を開く：橋付近と下の床を切り替え。別の高さの床は点模様で薄く残し、地図の位置関係を保ちます。
  • 手動で高さを選ぶ → プレイヤーを動かす：ワールドマップの高さは固定。「自分の高さ」で高さだけ追従に戻せます。
  • 保存した洞窟を見る → 地表 → 洞窟：洞窟の高さを覚えて戻ります。「自分に戻る」は位置・ディメンション・自動表示・高さ追従を戻します。
  • 地表にいるとき「洞窟」を開く：現在の高さに洞窟の記録がなければ、近い高さの記録を固定表示。未記録の高さには候補への入口を残します。

ゲームへ戻ったときのミニマップ

ワールドマップで過去の高さを選んでも、こちらは現在地を追う提案です。外側の「プレイヤーを動かす」で、両方の動きを比べられます。

  • 自動／地表／洞窟：自動は現在地に合わせ、明示的な地表・洞窟の選択は閲覧中に保持します。
  • 自分 Y…／固定 Y…：色に加えて文字で追従状態を示します。ドラッグは高さの追従を止めません。
  • 広く見る／高さを絞るは、戻る操作でも維持します。表示している床が歩いて到達できることを保証する表示ではありません。
  • 高さは見たい空間や足場を選ぶ手がかりです。記録候補、絞り方、描画範囲の数値から保存形式や空間判定方式は決まりません。

確認したいこと

  1. 普段は「広く見る」で溶岩湖や空洞の形を把握できるか。「高さを絞る」にすると上下に重なる足場を読み取りやすいか。
  2. 高さの選択パネル：入力・スライダー・記録済み候補を一緒に使える形は扱いやすいか。モックでは −／＋は 1 ブロック、Shift と一緒なら 8 ブロックです。
  3. 戻る操作：「自分の高さ」は高さだけ、「自分に戻る」は位置・表示も戻す。この違いが読み取れるか。
  4. 過去の洞窟を見返す：手動の高さと表示を保ち、ミニマップの現在地表示を変えない動きでよいか。

合意済み：今いる足場を優先・同じ空洞内の連続性・地上洞窟も保存して再閲覧。未確定：このページの新しい操作、ミニマップとの連動、色、空間の選択と切り替え、保存の表現。再入場・保存は想定する場面で、モックがゲームのデータを読み書きすることはありません。
