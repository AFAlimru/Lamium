スイッチと数字だけにする

A/B/C の「開いた UI が複雑」「スライダーが難しい」「1 文字ラベルは暗黙的」という反省から、操作そのものを減らした D 案です。洞窟＝オン/オフ、広く見る＝オン/オフ、高さ＝−/数字/＋、そして「自分の高さに合わせる」ボタンだけにし、スライダー・記録候補の一覧・3 択モード・追従トグルは外します。標準表示は「ネザー＝広く、Overworld 洞窟＝層」です。

バッジ：1行＝上バーが 1 行／2行＝2 行目を使う／はみ出し＝右端が切れる。地形は説明用の架空データです。

操作モデル

  • 洞窟：オンで洞窟、オフで地表。マップを開いたときは、いる場所に合わせて最初からオン/オフが決まります。歩いてる間に勝手に切り替わることはありません。
  • 広く見る：オンで空洞の底・溶岩まで、オフで選んだ高さの層。ネザーは最初からオン、Overworld 洞窟はオフ。
  • 高さ：− と ＋ は 1 ブロック、数字をクリックして直接入力もできます。スライダーはありません。
  • 自分の高さに合わせる：マップを開いたときは常に自分の高さから始まります。手動で高さを変えると固定になり、このボタンで自分の高さへ戻ります。トグルではなく実行ボタンです。
  • 自分に戻る：位置・次元・洞窟/地表・高さをまとめて戻します（今のまま）。

v1 で外したもの

  • スライダー（数字入力と ± で足りる）。
  • 記録候補の一覧（数字を直接入れれば飛べる）。必要なら後から「記録」ボタンとして足せます。
  • 自動/地表/洞窟の 3 択（洞窟スイッチのオン/オフに統合）。
  • 「広く/層」の 2 択ボタン（スイッチに統合）。
  • 追従トグル（「自分の高さに合わせる」実行ボタンに変更）。

確認したいこと

  1. パネルの位置：状態ボタンの真下に開くようにしました。一覧パネルが開いているときは、重ならないよう一覧を閉じてから出します。
  2. 自分の高さに合わせる：マップを開くと常に自分 Y から始まり、手動で変えると固定。戻すときはこの実行ボタン、でよいか。
  3. 記録候補なし：数字入力と ± だけで足りるか。必要なら後から小さな「記録」ボタンを足せます。
  4. ネザー：D の形で「洞窟は常に表示」＋「広く」＋「高さ」の 2 行半になる。これでよいか。
