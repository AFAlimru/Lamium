各案の意図

  • A 状態ボタン＋ポップオーバー：上バーは「自動 洞窟 層 Y68 ▾」の 1 つだけ。モード・広く/層・高さ・記録候補を中にまとめる。幅をほぼ増やさず、125% でも 1 行を守りやすい。
  • B 2 行目に常設：モード・広く/層・高さを 2 行目に並べる。発見しやすいが、125% では 3 行目に折り返すか、右端が切れる。
  • C 短縮ラベルで 1 行：「自／地／洞」「広／層」の 1 文字とアイコンで 1 行を狙う。慣れれば速いが、初見では意味が取りにくい。

見てほしいこと

  • 100% と 125% で、状態ボタンの文字が読めるか。特に「自動」「固定」「層」「広」の区別。
  • ポップオーバーを開いたとき、高さの数値・スライダー・記録候補が一緒に使えるか。
  • 2 行目常設（B）の地図の狭さと、1 行（A/C）の窮屈さのどちらが許容できるか。
  • バーを 17/13 にすると、100% で読みやすくなるか。125% で逆に窮屈にならないか。

確認したいこと

  1. レイアウト：A／B／C のどれを採用するか。A を推奨、次点 C。B は 125% で 3 行になりやすい。
  2. バーの大きさ：現行 15/11 のままか、17/13 に上げるか。上げると 125% では少し窮屈になる。
  3. ネザーの層操作：今の「◀ Y64〜79 ▶」を A の状態ボタンに統合してよいか。残す場合は、広く/層の切替をどこに置くか。
  4. 標準表示：ネザー＝広く、Overworld 洞窟＝層、でよいか。ミニマップは前回どおり「広く」で現在地追従のまま。
